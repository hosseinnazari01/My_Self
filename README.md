🎨 Personal Website Styling | طراحی استایل وب‌سایت شخصی

این فایل CSS برای طراحی ظاهری و زیباسازی وب‌سایت شخصی من نوشته شده است.

در این پروژه از CSS برای تغییر رنگ متن‌ها، اندازه فونت، نوع قلم، نحوه قرارگیری نوشته‌ها و رنگ پس‌زمینه صفحه استفاده شده است.

🎨 CSS Sections

1. Paragraph ("p")

- تعیین رنگ متن با استفاده از "color".
- تنظیم اندازه فونت با "font-size".
- راست‌چین کردن متن با "text-align".
- انتخاب نوع قلم با "font-family".
- تنظیم حالت ظاهری فونت با "font-style".

2. Ordered List ("ol")

- تنظیم اندازه نوشته‌های فهرست.
- انتخاب نوع قلم Sans-serif.
- تعیین رنگ متن فهرست.

3. Body ("body")

- تنظیم رنگ پس‌زمینه کل صفحه به رنگ مشکی با "background-color".

4. Links ("a")

- بزرگ‌تر کردن اندازه نوشته لینک‌ها.
- تعیین رنگ پس‌زمینه لینک‌ها با استفاده از "background-color".
